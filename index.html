Full-Stack Blueprint & UI/UX Research Vue.js 3 + GAS + GitHub Pages

Arsitektur Decoupled GAS & Dokumentasi UI/UX

LAYER 1 • FRONTEND SPA

GitHub Pages + Vue.js 3

Dihosting statis di GitHub Pages dengan CDN global. Mengelola state reaktif menggunakan Vue 3 Composition API, menyimpan cache lokal (localStorage) untuk akses instant-load, dan mengirim request HTTP ke GAS.

LAYER 2 • API GATEWAY

Google Apps Script (Web App)

Menjalankan controller doGet(e) & doPost(e). Menggunakan Content-Type: text/plain;charset=utf-8 agar bebas preflight CORS, CacheService (TTL 5 menit), dan LockService untuk keamanan transaksi tulis.

LAYER 3 • RELATIONAL DB

Google Sheets (3 Tabel)

Basis data cloud tanpa biaya yang terdiri atas 3 lembar kerja terhubung: Siloka_Master (data utama), Glossary_Items (relasi 1-to-N kamus buhun), dan User_Reflections (jurnal tafakur).

Solusi Kunci Masalah Teknis Decoupled GAS + GitHub Pages:

1. Bypass CORS Preflight (Tanpa Proxy Pihak Ketiga): Browser memblokir POST application/json ke script.google.com karena GAS tidak merespons metode OPTIONS. Dengan mengirim JSON sebagai text/plain;charset=utf-8 dan redirect: 'follow', request langsung diterima oleh JSON.parse(e.postData.contents).
2. Stale-While-Revalidate & ScriptCache: Mengatasi cold-start Google Apps Script (1.5–2.5 detik) dengan menyajikan data dari localStorage secara instan di browser sembari memperbarui data di latar belakang dari CacheService GAS.
